# v16：積載後の実姿勢を搬入判定へ反映する実験

## 確認した実装

`src/ground_handling/items.py`では、硬い荷物も柔らかい荷物も固定寸法のGEOM_BOXとして生成する。is_softの場合はcontactStiffness、contactDamping、linearDampingを変更する。箱の寸法を圧縮率で変更する処理やsoft body生成はない。接触の柔らかさによるめり込み・沈下は、箱の寸法変化とは区別する。

`containers.py`のupdate_packed_itemsは積載済み荷物の位置・クォータニオンを更新する。観測には元の寸法、実位置pos、実姿勢orn、柔らかさと接触物性が返る。

v14/v15の_effective_packedは観測された位置を優先する。しかし_oriented_packedは、記録した6種類の選択姿勢で寸法を並べ替え、実クォータニオンの微小な傾きを搬入形状に反映しない。

## 実験版の変更

v15を継承する新しい`agents/search_cand_v16_observed_pose/agent.py`を追加した。元のv15、シミュレータ、C++実装、評価条件は変更していない。

観測された固定箱の回転行列Rと元寸法dから、軸に平行な外接箱の寸法`abs(R) @ d`をPythonで計算する。観測実位置とその外接箱を、既存のY→X搬入経路ガードへ渡す。寸法・傾きごとに占有範囲が変わるため、一律のクリアランス上乗せは行っていない。

この外接箱は「荷物が膨張した」という推定ではなく、実際に回転した固定箱を囲う保守的な範囲。公称体積や支持面の計算には流用しない。回転した外接箱の上面は平らな支持面とは限らないためである。

内部の未観測配置には従来形状を使い、有効な実クォータニオンが得られた場合だけ更新する。新たな圧縮モデルや物理エンジンは実装していない。C++は既存の高速幾何学判定を維持する。

## 検証

`scripts/test_observed_pose.py`の3テストで、(1)複数の回転姿勢の外接箱をPyBullet getAABBと比較、(2)微小な傾きで旧判定は通過するが新判定は拒否する経路、(3)観測欠落・無効値でのフォールバックを確認した。すべて通過。

実評価の結果は`docs/v16_observed_pose_validation.json`に保存する。評価対象は開発用101・103・112・123と元000・001。保留用ケースは今回の調整に使用していない。比較元はPR #3に保存済みのv15基準結果であり、同時刻・同一CPU負荷の対照実験ではない。時間制限付き探索なのでCPU負荷による影響もあり得る。

## 限界と次の課題

- お手元のログでは101の搬入14手目、荷物38と15の距離が14.990854mmとなり拒否された。GUI終了後のSegmentation faultは別件。
- 実姿勢の取りこぼしはコード上で確認したが、お手元の約9µm不足の原因と断定できない。この環境でその荷物対の衝突を再現したわけではない。
- 外接箱は大きな回転で過剰に保守的になり得る。拒否後の別配置・再計画を併せて検討する必要がある。
- 支持面の傾き・接触変形の将来予測までは未対応。観測済みの位置変化を使うことと、次の積載で生じる沈下を予測することは異なる。
- 全30ケースの改善や提出スコア向上は未確認。実験版を提出版へ自動置換しない。

## 再実行

リポジトリのルートで実行する。環境構築済みのPython 3.12と外部checkerを使う場合：

```bash
export NEDO_CLOUD_STATE="$HOME/nedo-robustness"
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 EP_CPP_MODE=cpp \
SC_SEARCH_TRIALS=16 SC_SEARCH_MAX_SECONDS=60 \
SC_FEASIBILITY_BEAM=12 SC_FEASIBILITY_BRANCH=8 \
"$NEDO_CLOUD_STATE/venv/bin/python" scripts/cloud_run.py \
  --config-path cases/101.json \
  --module-path agents/search_cand_v16_observed_pose/ \
  --verbose True
```

外部checkerの構築手順はdocs/codex-cloud.md、30ケースの生成・計測手順はPR #3を参照。Pythonのactivateは不要。結果は外部STATE/runsの新しいディレクトリへ保存される。
